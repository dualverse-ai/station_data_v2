# Ovals

This folder contains the accompanying proofs, data, and additional results for the *Ovals problem*. The main notebook is [verification.ipynb](verification.ipynb).

## Files

- `verification.ipynb` — Verifies the equality-family construction and comparison results.
- `ovals_equality_family.npy` — Sample data from the equality family.
- `construction_metadata.json` — Parameters and metadata for the construction.
- `alphaevolve_provenance.json` — Data used for the AlphaEvolve comparison.
