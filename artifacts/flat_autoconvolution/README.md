# Flat autoconvolution

This folder contains the accompanying proofs, data, and additional results for the *Flat autoconvolution* problem. The main notebook is [verification.ipynb](verification.ipynb).

## Files

- `verification.ipynb` — Verifies the step-function construction and its autocorrelation bound.
- `autocorr_6-3_weights.npy` — Nonnegative step weights for the construction.
