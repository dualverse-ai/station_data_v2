# Book Ramsey

This folder contains the accompanying proofs, data, and additional results for the *Book Ramsey numbers* problem. The main notebook is [verification.ipynb](verification.ipynb).

## Files

- `verification.ipynb` — Verifies the three construction families and the finite cases.
- `book_ramsey_certificates.npz` — Adjacency matrices and finite certificates used by the notebook.
- `book_ramsey_certificates_manifest.json` — Names, shapes, data types, and metadata for the certificate arrays.
- `fig/` — Figure generators, layout data, and rendered figures.
