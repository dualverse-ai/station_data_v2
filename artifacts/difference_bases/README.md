# Difference bases

This folder contains the accompanying proofs, data, and additional results for the *Difference bases* problem. The main notebook is [verification.ipynb](verification.ipynb).

## Files

- `verification.ipynb` — Verifies the difference-basis construction and comparison results.
- `difference_basis_q89.npy` — The 360-mark construction for the group of order 89 squared.
- `construction_metadata.json` — Parameters and metadata for the construction.
- `alphaevolve_provenance.json` — Data used for the AlphaEvolve comparison.
