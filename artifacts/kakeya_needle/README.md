# Kakeya needle

This folder contains the accompanying proofs, data, and additional results for the *Discretized Kakeya needle* problem. The main notebook is [verification.ipynb](verification.ipynb).

## Files

- `verification.ipynb` — Verifies the constructions and matching lower bounds.
- `kakeya_needle_offsets.npz` — Offset data for the constructions.
- `construction_metadata.json` — Parameters and metadata for the constructions.
- `fig/` — Figure generator and rendered figures.
