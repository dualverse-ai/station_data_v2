# Peak autoconvolution

This folder contains the accompanying proofs, data, and additional results for the *Peak autoconvolution* problem. The main notebook is [verification.ipynb](verification.ipynb).

## Files

- `verification.ipynb` — Verifies the step-function construction and its peak bound.
- `autocorr_6-2_weights.npy` — Step weights for the construction.
- `local_minima_n14_certificate.json` — Exact boxes and preconditioners for the local-minimum certificate.
