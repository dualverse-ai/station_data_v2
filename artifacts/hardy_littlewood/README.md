# Hardy–Littlewood

This folder contains the accompanying proofs, data, and additional results for the *Hardy–Littlewood maximal inequality* problem. The main notebook is [verification.ipynb](verification.ipynb).

## Files

- `verification.ipynb` — Verifies the construction and its pairwise-sum coverage.
- `hardy_littlewood_356.npy` — Exact positions and weights for the construction.
- `construction_metadata.json` — Parameters and metadata for the construction.
